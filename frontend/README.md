# RepairFlow — фронтенд

Vue 3 + TypeScript + Tailwind CSS 4, сборка на Vite.

## Запуск

```bash
npm install
cp .env.example .env   # при необходимости поправьте адрес API
npm run dev            # http://localhost:5173
```

Бэкенд поднимается отдельно из корня репозитория (`docker compose up`) и слушает http://localhost:5080.

```bash
npm run build       # типы + продакшн-сборка в dist/
npm run type-check  # только проверка типов
npm run preview     # локальный просмотр собранной версии
```

## Структура

```
src/
  api/          типы контрактов, axios-клиент, обёртки эндпоинтов
  realtime/     подключение к SignalR-хабу (протокол MessagePack)
  stores/       Pinia: авторизация и тосты
  router/       маршруты с guard'ами по ролям
  lib/          форматирование и палитра статусов
  components/   ui — элементы дизайн-системы, orders и dashboard — прикладные
  views/        экраны
```

## Что стоит посмотреть в коде

**`api/client.ts` — тихое обновление токена.** Access-токен живёт только в памяти вкладки: класть его в
localStorage нельзя, оттуда его достанет любой XSS. Долгоживущий refresh лежит в httpOnly-куке, поэтому
после F5 сессия поднимается запросом `/auth/refresh`. Перехватчик ловит 401, обновляет пару токенов и
повторяет исходный запрос — параллельные запросы при этом ждут одно обновление, а не устраивают гонку.

**`realtime/orderEvents.ts` — живые обновления.** Подписка на события конкретной заявки по WebSocket с
бинарным протоколом MessagePack. Если хаб недоступен, страница просто работает как обычная — уведомления
это бонус, а не условие работы.

**`components/orders/StatusTimeline.vue` — шкала статусов.** Путь заявки нарисован временной шкалой:
пройденные шаги залиты цветом своего статуса, текущий пульсирует, будущие контурные, под каждым — дата и
автор перехода из истории.

**`components/dashboard/OrdersChart.vue` — график без графической библиотеки.** Инлайновый SVG: две серии,
линии 2px, сплошная волосяная сетка, подписи на концах линий с выносками при схлопывании, наведение с
подсказкой и таблица-двойник для тех, кому цвет недоступен. Пара цветов проверена на различимость при
дальтонизме.

## Деплой

`vercel.json` описывает сборку и одно правило: любой путь отдаёт `index.html`. Это нужно, чтобы
прямая ссылка на `/orders/<id>` открывалась, а не отдавала 404 — маршрутизация у SPA происходит
в браузере. Статические файлы из `dist` это правило не перехватывает: Vercel сначала ищет файл
на диске и только потом применяет rewrites.

Схема `vercel.json` строгая и не допускает посторонних ключей, комментариев в нём быть не может —
поэтому пояснение живёт здесь.

## Дизайн

Современный flat на индиго. Палитра, шрифты (Manrope + Inter), шкала отступов и цвета статусов
зафиксированы в [`../docs/design-system.md`](../docs/design-system.md) и продублированы токенами
в `src/style.css`. Новые экраны собираются из существующих компонентов `components/ui`.
