# Дизайн-система RepairFlow

Современный flat: плоские заливки, без градиентов и теней-«объёма», одна тонкая рамка вместо тени,
акцент — индиго. Правило простое: цветом выделяется действие и статус, всё остальное — нейтральное.

## Палитра

| Роль | Токен | HEX | Где применяется |
|---|---|---|---|
| Акцент | `indigo-600` | `#4F46E5` | основные кнопки, активные пункты меню, ссылки |
| Акцент (hover) | `indigo-700` | `#4338CA` | наведение и нажатие |
| Акцент (фон) | `indigo-50` | `#EEF2FF` | подложка активной строки, бейджи |
| Текст | `slate-900` | `#0F172A` | заголовки и основной текст |
| Текст вторичный | `slate-500` | `#64748B` | подписи, метаданные, плейсхолдеры |
| Границы | `slate-200` | `#E2E8F0` | рамки карточек, разделители, инпуты |
| Фон страницы | `slate-50` | `#F8FAFC` | подложка приложения |
| Поверхность | `white` | `#FFFFFF` | карточки, таблицы, модальные окна |

Всего шесть цветов плюс белый — этого достаточно. Дополнительные оттенки берутся только для статусов.

## Цвета статусов заявки

| Статус | Цвет | HEX |
|---|---|---|
| Новая | `slate-500` | `#64748B` |
| Диагностика | `sky-500` | `#0EA5E9` |
| Ожидает подтверждения сметы | `amber-500` | `#F59E0B` |
| В работе | `indigo-600` | `#4F46E5` |
| Готова к выдаче | `emerald-500` | `#10B981` |
| Выдана | `emerald-700` | `#047857` |
| Отменена | `slate-400` | `#94A3B8` |
| Отказ клиента | `rose-500` | `#F43F5E` |

Приоритеты: низкий — `slate-400`, обычный — без пометки, высокий — `rose-500`.

## Типографика

- Заголовки: **Manrope** 600/700 — характерный, но спокойный гротеск.
- Текст и интерфейс: **Inter** 400/500.
- Числа в таблицах и суммы — с `font-variant-numeric: tabular-nums`, иначе колонки «пляшут».

Размеры: 30 / 24 / 20 / 16 / 14 / 12 px. Межстрочный — 1.5 для текста, 1.2 для заголовков.

## Шкала отступов

4 · 8 · 12 · 16 · 24 · 32 · 48 px. Промежуточных значений нет — если чего-то не хватает,
берётся ближайшее из шкалы.

Скругления: 8 px для кнопок и инпутов, 12 px для карточек, 999 px для бейджей.
Тени: одна `0 1px 2px rgba(15, 23, 42, .06)` для карточек и `0 8px 24px rgba(15, 23, 42, .12)`
для модальных окон. Больше теней в проекте нет.

## Запоминающаяся деталь

Статусы заявки в карточке рисуются **горизонтальной временной шкалой**: пройденные шаги залиты
цветом статуса, текущий пульсирует, будущие — контурные. Под каждым шагом — дата и автор перехода
из истории. Одна такая деталь работает лучше десяти украшений.

## Состояния, о которых нельзя забыть

- Скелетоны при загрузке списков и карточки — не спиннер по центру экрана.
- Пустые состояния с призывом к действию: «Заявок пока нет» + кнопка «Создать заявку».
- Ошибки формы — под полем, красным, с понятным текстом с сервера (`ProblemDetails`).
- Видимый фокус на клавиатуре: кольцо `indigo-600` толщиной 2 px со смещением 2 px.
- Адаптив: таблица заявок на мобильном превращается в список карточек.
