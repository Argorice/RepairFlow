# docs

Сюда кладутся материалы для витрины проекта:

- `dashboard.png` — дашборд менеджера
- `orders.png` — список заявок с фильтрами
- `order-card.png` — карточка заявки со шкалой статусов
- `demo.gif` — 20-секундный проход по сценарию: клиент создал → менеджер назначил → мастер собрал смету → клиент подтвердил

Скриншоты снимаются в разрешении 1440×900, gif — не длиннее 20 секунд и не тяжелее 5 МБ,
иначе GitHub не покажет его в README.

Как только `dashboard.png` появится, верните строку в корневой README сразу под ссылкой на демо:

```markdown
![Дашборд](docs/dashboard.png)
```

Пустая рамка «изображение не загрузилось» в портфолио выглядит хуже, чем её отсутствие,
поэтому ссылка добавляется вместе с файлом, а не заранее.
